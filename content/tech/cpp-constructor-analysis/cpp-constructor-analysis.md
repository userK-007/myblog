构造函数是 C++ 对象生命周期中最关键的机制之一，其作用是在对象创建阶段完成初始化工作，确保对象进入可用且一致的状态。围绕构造函数，C++形成了一整套规则体系，涵盖默认构造、参数化构造、拷贝语义、移动语义以及初始化策略等多个层面。

本文对相关知识进行统一梳理，形成一套从基础到进阶完整一致的认知框架。

---

## 一、构造函数的本质与规则

构造函数是类中的特殊成员函数，在对象创建时自动调用，用于初始化成员变量。

其基本约束如下：
- 名称必须与类名相同
- 无返回类型（包括 `void`）
- 通常声明为 `public`
- 支持重载（可存在多个构造函数）
- 不可为 `virtual`

```cpp
class A {
public:
    A() {}  // 构造函数
};
```
### 核心语义
对象的构造分为两个阶段：
1. **初始化阶段（优先执行）**
    - 成员变量初始化
    - 基类构造
    - 初始化列表执行
2. **构造函数体执行阶段**
    - 执行 `{}` 内逻辑
因此，构造函数体内的赋值并不等价于初始化。

## 二、默认构造函数机制

### 2.1 定义

默认构造函数是不接收参数或所有参数都有默认值的构造函数。
```cpp
class A {
public:
    A() {}
};
```
### 2.2 编译器行为
若用户未定义任何构造函数，编译器可能生成"合成默认构造函数"。
其行为特点：
- 内置类型（int、double、指针）：不保证初始化（值未定义）
- 类类型成员：调用其默认构造函数

### 2.3 规则变化（关键点）
一旦用户定义以下任意函数：
- 任意构造函数
- 拷贝构造函数
- 移动构造函数
编译器通常**不再自动生成默认构造函数**。
如需保留默认构造能力：
```cpp
A() = default;
```

## 三、参数化构造函数
用于在对象创建时显式提供初始状态。
```cpp
class A {
public:
    int x;
    A(int v) : x(v) {}
};
```
### 3.1 初始化列表 vs 函数体赋值
#### （1）初始化列表（推荐）
```cpp
A(int v) : x(v) {}
```
特点：
- 真正意义上的初始化
- 更高效（避免二次赋值）
- 必须用于：
    - `const` 成员
    - 引用成员
    - 无默认构造的成员对象
#### （2）函数体赋值
```cpp
A(int v) {
    x = v;
}
```

特点：
- 先默认初始化，再赋值
- 存在额外开销
- 不适用于 const / reference

## 四、拷贝构造函数
### 4.1 定义形式
```cpp
class A {
public:
    A(const A& other) {}
};
```
必须使用**同类型的常量引用**。

---
### 4.2 触发场景
拷贝构造函数在以下情况下调用：
- 对象初始化另一个对象
- 按值传参
- 按值返回对象

```cpp
A a1;
A a2 = a1;   // 拷贝构造
```
---
### 4.3 默认行为：浅拷贝
编译器生成的默认拷贝构造函数执行逐成员复制：
- 基本类型：值复制
- 指针类型：地址复制（关键风险点）
#### 风险
若类包含动态资源：
```cpp
class A {
public:
    int* p;
};
```

则两个对象共享同一内存：
- 析构时 double free
- 修改互相影响
---
### 4.4 深拷贝解决方案
必须手动实现资源复制：
```cpp
class A {
public:
    int* p;
    A() { p = new int(10); }
    A(const A& other) {
        p = new int(*other.p);
    }
    ~A() { delete p; }
};
```

## 五、移动构造函数（C++11）

移动构造函数用于"资源转移"而非复制。
### 5.1 定义形式
```cpp
class A {
public:
    A(A&& other) noexcept {}
};
```
---
### 5.2 核心机制

移动语义基于：
- 右值引用 `&&`
- `std::move`
本质是：
> 转移资源所有权，而不是复制资源
```cpp
A a1;
A a2(std::move(a1));
```
---
### 5.3 实现逻辑
典型实现：
```cpp
A(A&& other) noexcept {
    p = other.p;
    other.p = nullptr;
}
```
关键点：
- 接管资源指针
- 原对象置空，避免析构重复释放
---
### 5.4 noexcept 的意义
标准库容器（如 vector）在扩容时：
- 优先选择 move
- 前提：移动构造不抛异常
因此推荐：
```cpp
A(A&&) noexcept;
```

## 六、构造函数访问控制
构造函数可以控制对象创建权限：

|权限|效果|
|---|---|
|public|任意创建对象|
|protected|仅派生类可创建|
|private|禁止外部创建|

典型用途：
- 单例模式
- 工厂模式控制对象创建

## 七、初始化列表的本质优势

### 7.1 执行顺序
成员初始化发生在构造函数体之前。
### 7.2 性能差异

|方式|过程|效率|
|---|---|---|
|初始化列表|直接初始化|高|
|函数体赋值|先默认构造再赋值|低|

## 八、典型总结
### 构造函数类型对比

| 类型   | 参数       | 作用      | 关键点     |
| ---- | -------- | ------- | ------- |
| 默认构造 | 无        | 对象默认初始化 | 可能被覆盖   |
| 参数构造 | 自定义      | 显式初始化   | 推荐初始化列表 |
| 拷贝构造 | const T& | 对象复制    | 注意深浅拷贝  |
| 移动构造 | T&&      | 资源转移    | 提升性能    |
